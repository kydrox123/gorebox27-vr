# История версий

## v1

- Добавлен лаунчер на Electron для Windows x64.
- Добавлены установка VR-патча и восстановление файла игры из интерфейса.
- Добавлен запуск через Steam с проверкой подключения шлема и обоих контроллеров.
- Добавлена анимированная галерея скриншотов GoreBox.

Поддерживается сборка GB27 0.16.3 (Steam 26471092). Новая физика рук, захват NPC и изменения игровых действий в v1 не входят.
